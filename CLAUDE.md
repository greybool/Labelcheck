## Правила
- Сбой → сначала показать сырые данные в точке отказа, потом гипотезы.
- Перед изменением кода: «Что/Почему/Риск» → ждать OK.
- Одна тема обсуждения за раз.
- Репо публичный: не коммитить ключи, данные компании, личные пути. .env в .gitignore.
  Перед КАЖДЫМ коммитом: `python tests/test_repo_hygiene.py` (смотрит индекс git,
  ловит и бинарники — grep по текстам архив с .env не поймал, инцидент 04.09).
  Коммитить только явным списком файлов, никогда `git add .`.
  Скриншоты в README/docs — только с демо-макета (`data/samples/demo_label.pdf`)
  и демо-журнала; реальные макеты, бренды и имена файлов компании — нет.
- Метрики retrieval: всегда Hit@1/3/5/10 + MRR, все пять.
- Вердикт без цитаты пункта регламента = статус «требует ручной проверки», не угадывать.
- Конфиги (аспекты, модели, пороги) — в YAML/.env, не в код.
- Скоуп: только то, что в ТЗ; идеи — в BACKLOG.md.
- Напоминать о коммитах: список файлов ✅/❌, Summary (англ., imperative, ~50 симв.), Description 1–3 предложения (англ.).
- Handoff-документы: только новые файлы в handoffs/handoff-NN.md, старые не перезаписывать.

## Стек
Python 3.12, OpenAI API (CHEAP_MODEL + MAIN_MODEL из .env), text-embedding-3-small,
Qdrant (docker) + BM25, Streamlit, SQLite, docker-compose. Без Ollama, без OCR.
